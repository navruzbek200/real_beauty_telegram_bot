{% comment %} Video upload field. Django's stock file input is a grey "Choose file" button and, once something is saved, a bare link to the stored path. For a shop owner publishing a course that is not enough to work with: they need to see that the right clip landed, how long it runs, and — on a 40 MB upload over a phone tether — that anything is happening at all. So this widget does three things the default cannot. It accepts a drop. It plays the chosen file back immediately from a local object URL, before any byte has been sent, which is the only preview that costs nothing. And it reports upload progress, by taking over the submit with XHR — with a plain fallback: if XHR is unavailable or the request fails, the form is submitted the ordinary way and the browser handles it as it always did. {% endcomment %}
