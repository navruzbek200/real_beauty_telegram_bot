# Real Beauty CRM — frontend

React 19 + TypeScript + Vite SPA, Feature-Sliced Design. See the repo root
[`README.md`](../README.md#api-va-react-spa) for setup, env vars, the FSD
layer rules, and how types are generated from the backend's OpenAPI schema.

Quick start:

```bash
npm install
cp .env.example .env
npm run generate:types   # backend must be running
npm run dev
```
